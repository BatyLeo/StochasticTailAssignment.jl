StochasticTailAssignment.ForwardExtensionFunction — Type
struct ForwardExtensionFunction

Data structures defining the forward extension functions for the column generation algorithm. It lives on the arcs of the graph. It is used to expand resources at the tail of arcs (see TailForwardResource). The considered node index of the arc is stored in the field activity_index.

Fields

  • operational_cost::Float64: leg cost of node + chaining cost

  • λ::Float64: dual variable λ of node

  • root_delays::Vector{Float64}: root delay of node for each scenario

  • slack_with_turn_time::Float64: slack (with turn time) between the two activities of the arc

  • activity_index::Int64: activity index of node

  • is_tail_maintenance::Bool: true if tail of arc is a maintenance activity (or dummy), used for knowing when not to compute delay costs

struct TailBackwardExtensionFunction

Data structures defining the backward extension functions for the column generation algorithm. It lives on the arcs of the graph.

FIELDS

  • root_delays::Vector{Float64}: root delay for each scenario of the arc tail

  • slack_with_turn_time::Float64: slack between the two activities of the arc

  • operational_cost::Float64: operational cost of the arc tail + chaining cost

  • λ::Float64: dual variable λ of the arc tail

StochasticTailAssignment.stochastic_column_generation — Method
stochastic_column_generation(
    instance::StochasticTailAssignment.AircraftRoutingBase.AbstractSchedule,
    initial_paths::Vector{StochasticTailAssignment.AircraftRoutingBase.Route};
    model_builder,
    root_delays,
    delay_cost_function,
    max_nb_columns,
    tol,
    silent,
    backward,
    add_all_columns,
    starting_sweep
)

Perform column generation to solve the stochastic tail assignment problem.

Arguments

  • instance: an instance of AbstractSchedule (also works with MaskedSchedule)
  • initial_paths: initial paths to start the column generation, should at least include one path per aircraft
  • model_builder: function to build the JuMP model
  • root_delays: root_delays[s, l] is the delay of leg l in scenario s
  • delay_cost_function: function mapping delays to costs
  • max_nb_columns: maximum number of columns to generate
  • tol: tolerance for reduced cost
  • silent: whether to print information

Returns:

  • columns: vector of generated columns as a Vector{Route}
  • model: final JuMP model
  • VV: reduced cost evolution for each aircraft
