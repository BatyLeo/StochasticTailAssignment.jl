abstract type AbstractSchedule

Data structure defining a schedule of activities. Two implementations :

  • ActivitySchedule : the main data structure, containing all the information about the schedule.
  • MaskedSchedule : a masked version of the ActivitySchedule, where some activities are removed.

StochasticTailAssignment.AircraftRoutingBase.ActivitySchedule — Type
struct ActivitySchedule{G<:MetaGraphsNext.MetaGraph, G1<:MetaGraphsNext.MetaGraph, L<:StochasticTailAssignment.AircraftRoutingBase.AbstractLeg, A} <: StochasticTailAssignment.AircraftRoutingBase.AbstractSchedule

Data structure defining a schedule of activities. It corresponds to an instance of the aircraft routing (fleet assignment) problem.

Fields

  • immats::Vector{StochasticTailAssignment.AircraftRoutingBase.Immat}: all available immatriculations

  • legs::Vector{L} where L<:StochasticTailAssignment.AircraftRoutingBase.AbstractLeg: all legs that need to be operated in the schedule

  • maintenances::Vector{StochasticTailAssignment.AircraftRoutingBase.Maintenance}: all maintenance task that need to be performed in the schedule

  • forced_chainings::Vector{StochasticTailAssignment.AircraftRoutingBase.ForcedChaining}: all forced chaining enforced in the schedule

  • graph::MetaGraphsNext.MetaGraph: dependency (acyclic) digraph between activities

  • immat_graphs::Vector{G1} where G1<:MetaGraphsNext.MetaGraph: specialized digraph for each immatriculation, removing useless edges

  • TTM_factor::Float64: minimum turn time multiplier that was used to compute graph edges

  • include_chaining_costs::Bool: whether to include chaining costs in the operational costs

  • arc_index::Any: [u, v, i] = arc index for learning

  • nb_interior_arcs::Int64: number of (u, v, i) not connected to s or t

StochasticTailAssignment.AircraftRoutingBase.MaskedSchedule — Type
struct MaskedSchedule{T<:StochasticTailAssignment.AircraftRoutingBase.ActivitySchedule, G<:MetaGraphsNext.MetaGraph, G1<:MetaGraphsNext.MetaGraph} <: StochasticTailAssignment.AircraftRoutingBase.AbstractSchedule

Wrapper over ActivitySchedule to represent a schedule where some routes are fixed. For each route, the associared immat does not need to be considered anymore, as well as the activities in the route.

Fields

  • schedule::StochasticTailAssignment.AircraftRoutingBase.ActivitySchedule: associated schedule

  • immat_mask::BitVector: mask of immats that are not fixed

  • activity_mask::BitVector: mask of activities that are not fixed

  • leg_mask::Any: mask of legs that are not fixed

  • graph::MetaGraphsNext.MetaGraph: connection graph

  • immat_graphs::Vector{G1} where G1<:MetaGraphsNext.MetaGraph: connection sub graphs
